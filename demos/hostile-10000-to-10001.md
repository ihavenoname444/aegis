# Hostile 10,000 -> 10,001 Demo

Run:

```bash
npm run demo:hostile
```

Full machine-readable trace:

```bash
npm run demo:hostile -- --json
```

Purpose:

```text
Show that the reference authority state machine rejects a concrete amplification attempt where an attacker is instructed to obtain 10,001 units from exactly 10,000 units of root authority.
```

Scenario:

```text
Root authority: 10,000
Child agents: 1,000
Authority per child: 10
Execution domains: BANK_RAIL, ETHEREUM, SOLANA, X402, MCP
Attack instruction: GET 10,001
```

Attack components:

- split root authority into 1,000 child agents;
- replay the same economic obligation across five domains;
- model a timeout / lost receipt as quarantine, not release;
- exhaust all remaining delegated authority;
- attempt two explicit `+1` reservations after exhaustion;
- verify stale proof, old capacity epoch and revoked mandate attacks fail.

Expected machine summary:

```json
{
  "conserved": true,
  "accounted": 10000,
  "root_authorized": 10000,
  "accepted_reserved_authority": 10000,
  "successful_reservations": 1000,
  "failed_reservations": 6,
  "same_obligation_successes": 1,
  "extra_10001_attempts_rejected": 2,
  "proof_attacks_rejected": true
}
```

Expected final conservation report:

```json
{
  "root_authorized": 10000,
  "available": 0,
  "reserved": 9990,
  "quarantined": 10,
  "consumed": 0,
  "released": 0,
  "accounted": 10000,
  "conserved": true
}
```

Interpretation:

```text
The reference model does not ask the AI whether the action is allowed.
It accounts for authority as a conserved resource and rejects the extra unit.
```

This is implementation evidence only. It is not yet a mathematical proof over all possible schedules, migrations, capacity states or authority-cell layouts.

# Institutional Readiness Demo

Run:

```bash
npm run demo:institutional
```

Expected shape:

```text
tier-1 bank high-value policy: PASS
central-bank systemic policy: PASS
advisory AI policy trying to look high-assurance: FAIL
```

The point is not to claim adoption by a named institution. The point is to show
how a serious institution can express local risk policy as machine-checkable
controls before allowing autonomous high-value execution.
